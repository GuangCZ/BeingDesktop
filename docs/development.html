开发与文档维护

源码、构建和静态文档。

项目结构

目录用途
src/Electron 主进程、预加载和服务桥接
renderer/桌面界面与本地资源
test/单元和界面验证
scripts/构建与验收脚本
docs/GitHub Pages 静态文档

修改与验证

npm ci
npm run check
npm test
node scripts/build-docs.cjs
node scripts/check-docs.cjs

修改设置 UI 后可运行 npm run test:theme，其他界面检查位于 test/ 和 scripts/。

文档部署

中文内容维护在 docs/content_CN.json。生成器输出独立 HTML 页面、搜索索引和站点地图；无需前端框架或外部字体。

文档在 main:/docs 维护，GitHub Pages 从 gh-pages 分支根目录部署。生成并提交后，在独立仓库运行 node scripts/publish-docs.cjs 发布更新。相对链接兼容本地预览与项目路径。

设计参考与许可

文档的信息组织参考 Codex 官方桌面文档的快速开始、功能指南和配置分区。页面内容与实现为 Being Desktop 独立编写，与 OpenAI 无隶属关系。

项目源码使用 MIT 许可，第三方组件及资源遵循各自许可。相关浏览器扩展见 BeingAnywhere。
