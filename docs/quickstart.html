开始使用

快速开始

安装桌面，连接 Loom，发送第一条消息。

1. 安装并打开

从下载与安装获取 Windows 版本。目录包请完整解压，再打开 Being Desktop.exe；便携 EXE 可直接运行。

2. 连接 Loom

在欢迎页填写已有 Being 的完整 Loom 地址及所需凭据。地址由你的 Being 服务提供。连接成功后，桌面加载对应的 Loom 对话。

远端地址使用 HTTPS；本机回环地址可使用 HTTP。模型 API 地址应在模型设置中填写。

3. 配置本机能力

跟随引导配置 Portal、Channel 和 Grove，也可以稍后在设置或 Town 中继续。只聊天时，可以先完成 Loom 连接。

需要 Being 使用本机文件或命令时，打开 设置 → 本机 Portal，选定工作区并连接这台电脑。

4. 开始对话

输入你要完成的事情。可粘贴图片，输入 / 选择工具，或创建新会话。使用 @ 提及时，留意发送前的篝火通知提示。

重新进入引导：设置 → 关于 → 继续新手引导。
