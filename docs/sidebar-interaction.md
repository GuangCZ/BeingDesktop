# Desktop 侧栏交互

侧栏围绕会话组织：顶部是新会话、搜索会话、围炉、篝火、工具与应用；中部依次显示已置顶、项目、独立会话；底部是当前 Being 菜单。围炉和篝火快捷入口直接打开对应页面，选中状态随页面和前进、后退导航同步。浏览器、控制台通过右上角工具按钮打开，再次点击可关闭。完整 Town 目录从工具与应用页面进入，功能任务记录从底部菜单进入。

项目行点击展开或折叠，鼠标悬停或键盘聚焦后显示新会话和更多菜单。会话支持点击切换、更多菜单或右键菜单、置顶、重命名、移到项目、归档。归档只修改本机侧栏元数据；搜索的已归档分类可以恢复原会话。移除项目只移除侧栏引用，不删除文件。旧会话不会被自动分配到当前文件夹。

项目会话新建及切换会使用它保存的本机目录，沿用既有文件与控制台边界，Portal 配置与权限独立。项目列表和按 Being 连接隔离的会话元数据保存在 Desktop 设置中；连接变化会拒绝过期写入，保存失败显示错误并保留原元数据。折叠与侧栏显隐偏好保存在本机界面配置中。

会话列表按最后消息时间排列；打开会话不会将它重新置顶。单行会话显示名称、相对时间、进行中状态，Worker 明细继续附在所属会话下面。所有分组共用一个滚动区域，底部菜单固定；切换到其他页面后取消会话选中高亮。

快捷键：Cmd/Ctrl+N 新会话，Cmd/Ctrl+K 搜索，Cmd/Ctrl+O 添加项目，Cmd/Ctrl+B 显隐侧栏，Cmd/Ctrl+1–9 切换会话，Cmd/Ctrl+[ / ] 导航，Cmd/Ctrl+J 控制台，Cmd/Ctrl+T 浏览器，Cmd/Ctrl+, 设置。搜索支持上下方向键、Enter 打开与 Esc 关闭；菜单和项目分组支持键盘操作。

交互参照：[官方项目与对话说明](https://learn.chatgpt.com/docs/projects)、[官方快捷键说明](https://learn.chatgpt.com/docs/reference/commands)。本机 Codex 窗口禁止自动读取，因此没有声称针对该窗口做像素级比对。

验证：`npm run test:sidebar` 使用真实 renderer 和 preload、隔离的会话及文件夹元数据执行界面检查；`npm test` 检查原生逻辑。测试不发送 Being 消息、不改写 Portal 配置。
