Windows x64 v0.8.25
开始使用

下载与安装

Windows x64 · 当前源码 0.8.22

获取桌面程序

在 GitHub Releases 中选择最新版本的 Windows 发布附件。若尚无发布附件，可按下方步骤从源码运行。

打开 Releases ↗

目录包运行时不需要另装 Node.js。解压后保留整个文件夹；单独移动 EXE 会缺少运行依赖。

从源码运行

准备 Windows x64、Node.js 24 和 npm，在仓库根目录执行：

npm ci
npm start

依赖包含原生终端模块；安装后若报告 ABI 不匹配，需为当前 Electron 重建 node-pty。

构建 Windows 包

npm run check
npm test
npm run pack

目录包位于 dist/win-unpacked。运行 npm run dist 生成便携 EXE。构建需要下载 Electron 和打包工具。

更新与配置

更新前从托盘菜单退出旧版，再打开新版。默认配置保存在当前用户的应用数据目录。通过项目 Start.ps1 启动时使用相同的默认用户数据目录。

Portal 更新是独立功能；其更新提示不会自动更新 Being Desktop。
