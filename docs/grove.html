Grove 工具市场

查找 Kit，确认环境，再安装。

浏览与检查

从 Town 打开工具市场，搜索 Kit 并查看详情。同名 Kit 通过发布者与 ID 区分。点击 检查安装环境 查看本机依赖、平台与账号状态。

安装与加载

符合已验证安装方案的 Kit 支持一键安装，也可批量安装可用项。安装会校验包、文件与协议；失败项显示具体原因。

安装成功但未加载时，使用 加载到 Portal 重试。文件安装、Portal 注册与实际业务调用是不同状态。

需要额外配置时

缺少包、平台不兼容或需要账号授权时，使用 请 Being 协助安装。桌面准备包含 Kit 信息和阻塞原因的草稿，由你检查并发送。

公开目录中的项目并非全部支持 Windows 一键安装。第三方服务账号与调用费用由各工具提供方决定。
