功能

文件、浏览器与终端

在对话旁检查资料和运行结果。

项目文件

点击侧栏项目旁的加号选择本机文件夹，在文件页浏览当前工作区。远端 Loom 的连接不会把远端文件或记忆迁移到这个文件夹。

内置浏览器

打开浏览器面板并输入网址，可在对话旁查看网页和本地预览。工具面板支持调整宽度。

编排任务的网页交付通过原会话“打开预览”进入此浏览器。静态产物由 Desktop 托管，动态项目仍需后台服务持续运行。

交互式 PowerShell

从控制台打开终端。每个标签是独立的持续会话，保留当前目录、变量与命令历史。新终端从选定工作区启动，没有工作区时从用户目录启动。

操作快捷键
执行命令Enter
历史 / 补全↑ ↓ / Tab
复制选区；无选区时中断Ctrl+C
粘贴Ctrl+V / Shift+Insert

切换标签或收起面板保留会话；关闭标签结束相应终端。当前目录以 PowerShell 提示符为准。

让 Being 使用桌面工具

标题栏的工具连接入口默认关闭。开启后，Being 发起的桌面工具调用仍逐次确认。获准命令在独立输出标签中展示。

桌面工具连接与 Portal 的工具权限分别管理。详见权限与数据。
