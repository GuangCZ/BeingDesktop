# 选中文本与解释卡片

原生聊天界面中，选中一条消息内的文本即可使用浮动菜单：

- **添加到对话**：把所选文本加入当前会话的输入框，保留已有草稿。引用默认折叠为数量标签，悬停或键盘聚焦可查看全文，可移除单条或全部引用。输入问题后，引用与问题一起发送；历史记录也保留引用样式。
- **更多详情**：打开独立的临时会话卡片，自动解释所选文本，支持流式回复、继续追问和停止当前卡片的回复。切换主会话时卡片随来源会话隐藏或恢复，主输入框保持原有草稿。

解释卡片使用独立的场景标识和内存中的记录，不加入侧栏会话列表或普通聊天缓存。关闭最后一张卡片、断开连接或重启应用后，临时记录不再在本地恢复。Being 服务端仍可能保留对话并共享记忆；这不是服务端的无痕模式。关闭卡片不强制中断 Being 正在进行的其他回复。

每条消息最多引用 12 段、合计 60,000 个字符；超限时提示缩小选择范围，不会静默截断。发送前失败会把引用和文本恢复到原会话，已受理的请求不会自动重发。

验证：`npm run test:chat` 覆盖消息编码、场景隔离、历史恢复、关闭时清理，以及离线 Electron 界面交互。界面测试使用模拟 Being，不发送真实消息。`npm test` 为全量单元测试，`npm run check` 为语法检查。
