开始使用

Being Desktop

让你的 Being，来到桌面。

一个桌面，连接现有 Being

Being Desktop 是面向 Windows 的 Being 客户端。连接已有 Loom，把对话、项目文件、浏览器、终端和本机 Portal 放在同一个工作区。

Being 的身份、记忆与自主行动仍由原来的运行时管理。首次使用需要已有的 Being 和 Loom 连接地址。

开始使用 ↗下载与安装

从这里开始

与 Being 对话 ↗多会话、图片、工具选择与消息定位。连接这台电脑 ↗配置本机 Portal，管理工具权限。扩展工具 ↗浏览 Grove，检查环境并安装 Kit。调整桌面 ↗外观、模型、连接和阅读设置。编排模式 ↗Being 拆分与验收，CLI Worker 执行，结果回到原会话。

当前版本

当前源码 0.8.22 · Windows x64。本轮重点加入严格编排模式、会话下的 Worker 执行状态、完成回调与验收、原会话结果卡和内置浏览器预览，并修复结果重复追加与模型错误展示。

从编排模式指南了解开启条件与使用边界。发布附件以 Releases 为准；服务可用性取决于所连接运行时及其授权。
