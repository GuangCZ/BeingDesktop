功能

对话与会话

保留上下文，组织不同任务。

会话与队列

在侧栏会话列表切换对话；点击新增会话可沿用当前语境创建会话。桌面为会话维护独立标识和消息记录。

状态面板展示当前会话的消息任务队列。已发送不等于运行时已经开始执行，其他渠道的队列不在此列表内。

图片输入

通过附件按钮、粘贴或拖放添加图片，确认预览后发送。0.8.19 已适配 Heart 的多模态请求格式。

实际识图需要当前模型与服务支持图片。其他类型附件的内容解析能力由上游服务决定。

选择工具与成员

输入 / 搜索网络搜索、网页读取及 Grove Kit。选择候选会更新草稿；发送后才由 Being 处理。

输入 @ 查找 Being 成员。带提及的消息发送时也会向公开篝火发布提及通知，请在发送前检查内容。

定位长对话

对话左侧的消息刻度支持悬停预览、点击跳转、拖动和滚轮逐条定位，也支持键盘操作。

功能任务可以查看进度、结果或错误，并把结果带回聊天草稿。停止本地追踪不代表服务端任务已取消。

Worker 任务与结果

启用编排模式后，执行任务显示在所属会话下。CLI 完成、通知送达与 Being 验收是不同状态；最终摘要和预览入口呈现在原会话。
