- Windows 64 位：运行 `windows-x64.exe`，或完整解压 `windows-x64.zip` 后运行。
- macOS Apple 芯片：选择 `macos-arm64.dmg` 或 `.zip`。
- macOS Intel：选择 `macos-x64.dmg` 或 `.zip`。

macOS 沿用项目现有的固定本地签名，未经过 Apple 公证。所有发布包的 SHA-256 见 `SHA256SUMS.txt`。
