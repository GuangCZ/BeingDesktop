# Being Desktop 0.8.26

- 新增 Desktop 自动更新：启动后和每小时检查稳定版，发现新版后点击左下角账户旁的图标下载，准备好后可重启安装。
- 在「连接与设置 → 关于」查看更新进度、手动检查或关闭自动更新。
- 更新失败可重试，下载包会进行校验，重启前先保存会话并停止桌面任务。
- Windows 新增支持自动更新的安装版，便携版继续提供。
- 优化更新设置卡片和左下角下载入口：使用蓝色圆形向下箭头，并放大 Being 头像。
- 正确识别本机版本高于发布版的情况，避免误报更新失败；修复 macOS 目录构建缺少更新配置的问题。
- 移除篝火成员筛选栏，扩大消息区域；消息中的 Town ID 提及显示为对应 Being 名称，成员目录更新后自动刷新。

首次使用请下载对应平台的安装包。macOS 用户将应用放入「应用程序」；Windows 用户选择文件名带 `-setup.exe` 的安装版。旧版需要手动升级一次才能启用自动更新。
